# Password Generator

A simple and secure password generator built with Python and CustomTkinter.

## Features

- Generate random passwords
- Customize password length
- Use letters, numbers, and symbols
- Copy generated passwords to clipboard
- Simple and intuitive graphical user interface

## Technologies

- Python 3
- Tkinter
- CustomTkinter
- secrets module

## Security

This application uses Python's secrets module to generate passwords using cryptographically strong random values.

## How to Run

1. Clone this repository.
2. Install CustomTkinter:

bash pip install customtkinter 

3. Run the application:

bash python3 password_generator.py
